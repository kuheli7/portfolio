Cloud · AWS cost analysis · Oct 2026 – present

CostLens

Explains why an AWS bill changed, down to the resource and the CloudTrail event.

Every morning it finds the service, resource and CloudTrail event behind a cost change and explains it in plain English on Slack. A deterministic engine computes every number; the LLM only writes sentences, and a validator rejects anything it invents.

  • 240/240injected incidents traced to the right root cause
  • To the centusage vs price split, checked by property tests
  • 720/720invented facts caught by the validator, per test tier

Results are on synthetic billing data. Not yet run against a live AWS account.

  • Python
  • FastAPI
  • AWS Lambda
  • EventBridge
  • CloudTrail
  • React
  • Slack
  • Hypothesis

Accessibility · Browser extension + local AI · Oct 2026 – present

VoiceNav

Hands-free browsing by voice: say “open the cheapest one” and it clicks the right link.

A Chrome and Edge extension for people who can’t easily use a mouse or keyboard. Rules handle the common phrases, code does the counting, and a small local LLM picks only from the labels actually on the page. No cloud, no API cost.

  • 64% → 94%command accuracy on a 50-command dev set
  • 82%on 28 held-out commands it was never tuned on
  • 72/74checks passed on 14 popular Indian websites
  • JavaScript
  • Chrome extension (MV3)

Data and ML · Credit risk · Sep 2026

CreditLens

Credit risk scoring that shows its reasons, with readable policy rules and plain-English questions.

A LightGBM model scores loan applicants from the Home Credit dataset, SHAP explains each decision, and a natural-language tool turns questions about the portfolio into checked SQL. FastAPI backend, plain JavaScript front end, shipped in Docker.

  • 0.233holdout PR-AUC, against a 0.081 no-skill baseline
  • 0.728holdout ROC-AUC
  • 144engineered features from 122 raw columns
  • Python
  • FastAPI
  • LightGBM
  • SHAP
  • Groq
  • SQLite
  • Chart.js
